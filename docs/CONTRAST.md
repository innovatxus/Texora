## Rules that follow from this table

- `line` (#ddd7cf) is a decorative hairline only. It must never be the sole boundary of an interactive control; inputs pair it with a `line-strong` focus/hover state and a visible label.
- `accent` is AA for text, so it may be used for link hover and loyalty copy.
- `ink-subtle` is the lightest colour permitted for any text.
